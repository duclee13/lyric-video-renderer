# Lyric Video Studio (`web/`)

Next.js (App Router + TypeScript + Tailwind CSS) web dashboard for `duclee13/lyric-video-renderer`.

- Deployed directly to **Vercel** with Root Directory set to `web`.
- Heavy WhisperX alignment and Remotion video rendering execute on **GitHub Actions** (`render-lyrics.yml`).
- See the root [`README.md`](../README.md) and [`.env.example`](./.env.example) for full setup and Vercel deployment instructions.
